# FAQ: What You Can and Cannot Do

Companion to [LICENSE](./LICENSE) · [TERMS.md](./TERMS.md) · [POLICY.md](./POLICY.md) · [COMMUNITY.md](./COMMUNITY.md)

---

## ✅ You CAN

| Question | Answer |
|---|---|
| **Build a game with Litt Engine?** | Yes — that's the entire point. |
| **Sell that game?** | Yes, commercially, without restriction. |
| **Crowdfund / fund game development?** | Yes, unlimited. |
| **Accept donations for your game?** | Yes, unlimited. |
| **Fork the engine?** | Yes, as long as the fork stays fully open-source. |
| **Build plugins, GUIs, editors?** | Yes — free, open-source, AI-exclusive workflows only. |
| **Accept donations for a tool you built?** | Up to **1 € per donor per month**. |
| **Train AI models using the engine?** | Yes. |
| **Sell AI models trained with the engine?** | Only if you have **contributed meaningfully** to the project (code, docs, fixes, testing, infra). |
| **Prompt an AI agent to build games for me?** | Yes — that is the intended human role. |

## ❌ You CANNOT

| Question | Answer |
|---|---|
| **Sell the engine or a fork of it?** | No. The engine is anti-commercial forever. |
| **Make a closed-source fork?** | No. All forks stay open-source, permanently. |
| **Charge for plugins/tools or add paid tiers?** | No. Tools are free; donations capped at 1 €/donor/month. |
| **Use "early access" or "support tiers" to charge more?** | No. That's loophole exploitation (LICENSE §11) and treated like selling. |
| **Accept unlimited donations for the engine itself?** | No. Max **1 € per donor per year**, no circumvention. |
| **Edit scenes / place assets / script gameplay directly as a human?** | No. Humans prompt agents; agents operate the engine. |
| **Use Litt as a human-driven game engine?** | No. It is AI-exclusive by design and by license. |
| **Sell trained models without contributing?** | No. Contribution is the price of model commercialization. |
| **Train agents for harmful/surveillance/discriminatory use?** | No, under any circumstance. |
| **Bypass caps via crypto tokens, bundles, split accounts…?** | No. Any circumvention = direct violation. |

## 🤔 Edge cases

- **"I made a free human-friendly editor"** → violates the AI-exclusive rule even at zero cost.
- **"My game's source is closed"** → fine! Games are not bound by the engine's open-source rule.
- **"I forked it and my fork adds monetized DLC tooling"** → the tooling is bound by the license; your *game content* is not.
- **"My company wants internal use"** → allowed if operated by AI agents, non-commercially, open-sourcing any distributed modifications.

Still unsure? Read [LICENSE](./LICENSE) §4–8 or open an issue.
