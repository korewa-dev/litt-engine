# litt-ecs\n\nEntity Component System for Litt Engine\n\n## Features\n\n- **Type-safe components** - Compile-time component type checking\n- **Fast queries** - Efficient entity filtering by component composition\n- **System ordering** - Optional system execution ordering\n- **Zero-cost abstractions** - No heap allocation for component lookups\n- **Tested** - Comprehensive unit tests\n\n## Quick Start\n\n```rust\nuse litt_ecs::*;\n\n#[derive(Default, Clone)]\nstruct Position { x: f32, y: f32 }\n\nlet mut world = World::new();\nlet entity = world.create_entity();\nworld.add_component(entity, Position { x: 1.0, y: 2.0 });\n\n// Get component\nlet pos = world.get_component::<Position>(entity).unwrap();\nprintln!("Position: ({}, {})", pos.x, pos.y);\n```\n\n## Systems\n\n```rust\n#[derive(Default, Clone)]\nstruct Velocity { dx: f32, dy: f32 }\n\nstruct MovementSystem { dt: f32 }\n\nimpl System for MovementSystem {\n    fn update(&mut self, world: &mut World, _dt: f32) {\n        for entity in world.query_entities_with::<Position, Velocity>() {\n            if let (Some(pos), Some(vel)) = (\n                world.get_component::<Position>(entity),\n                world.get_component::<Velocity>(entity),\n            ) {\n                world.add_component(entity, Position {\n                    x: pos.x + vel.dx * self.dt,\n                    y: pos.y + vel.dy * self.dt,\n                });\n            }\n        }\n    }\n}\n```\n\n## Integration with Litt Engine\n\n// In main.rs:\nlet mut world = litt_ecs::World::new();\nworld.add_system(MovementSystem { dt: 0.016 });\nworld.run_systems(0.016);
