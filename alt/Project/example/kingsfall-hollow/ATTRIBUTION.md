# ATTRIBUTION - kingsfall-hollow

All meshes generated procedurally by Litt Engine worldgen tools
(gen_archetype.py / gen_platformer25d.py / gen_props.py).
No third-party or human-authored assets. Materials are flat Kd colors
from themes.json / PALETTES tables. See assets/asset_index.json for the
per-file registry and NOTES.md for seeds.
