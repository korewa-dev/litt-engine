## 1. Correct inside-origin ray/AABB distance

Severity: RED.

Affected paths: `alt/src/native/littcore/litt_math.h` plus a currently gated canonical C++ contract test.

Validation evidence: current `ray_aabb` selects `r.t_max` when computed slab entry precedes `r.t_min`, so an inside-origin ray can report the ray's global far bound rather than computed slab exit `tmax`. For box `[-1,1]^3`, origin `(0,0,0)`, direction `+X`, interval `[0,10]`, current selection reports `10` although the forward AABB exit is `1`. Existing gated coverage does not exercise the inside-origin branch. This math surface is promoted by the authoritative support contract.

Repair: first add regressions for outside entry, inside exit, clipped inside miss, and parallel miss. Confirm the inside-origin test fails before implementation. Then make the smallest selection correction so the inside fallback uses computed `tmax`. Do not refactor unrelated slab, zero-direction, or boundary behavior.

Validation checks:

```sh
make engine-contract-test
make release-hardening-test
make -C alt/src/native cpp-sdk-test
```

Then require full Stabilization on the repair PR and exact merged main.

Regression risk: low if surgical; medium if unrelated slab logic is touched.

Merge readiness: blocked until fail-before/pass-after evidence exists and all targeted plus full gates are green.
