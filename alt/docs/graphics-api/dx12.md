# DirectX 12 Backend

**Status: unavailable in the generic Litt Engine renderer.**

The current `D3D12Device::initialize()` path deliberately returns failure. DXGI adapter enumeration, a production D3D12 device, swapchain, descriptor heaps, PSOs, shader compilation, resource allocation, and DXR are not release-supported by this backend.

No AMD, Intel Arc, NVIDIA, or other Windows GPU is certified for Litt Engine DX12 rendering.

## Promotion gate

DX12 remains unavailable until the complete promotion sequence in [graphics-api-status.md](graphics-api-status.md) is implemented, debug-layer and failure paths are exercised, sustained rendering and shutdown are tested, and physical hardware evidence exists for any vendor-specific claim.

Until then, callers must handle DX12 selection as unavailable.
