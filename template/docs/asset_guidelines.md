# Asset Guidelines

## Size Targets
- Total: < 5 MB
- Model: < 500 KB
- Texture: < 256 KB
- Shader: < 50 KB

## Formats
| Type | Format | Notes |
|------|--------|-------|
| Models | glTF 2.0 (.glb) | Binary |
| Textures | KTX2 | GPU-compressed |
| Shaders | SPIR-V (.spv) | Pre-compiled |

## Provenance
All assets in asset_index.json with source, license, SHA-256.
